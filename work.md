# Work Summary: Job Application Tracker

## Task Overview

I built a Job Application Tracker web app using Angular to help users manage their job applications. The app allows users to:

- Add, edit and delete job applications
- Track application status (Applied, Interviewing, Accepted, Rejected)
- See deadlines and interview dates on a calendar
- Manage state between components using Angular Services and RxJS
- Save data locally using LocalStorage

## Easy Tasks

- Setting up Angular project and modules
- Creating basic components like Job List, Job Form, and Calendar
- CRUD operations for job applications
- Using Angular Services to share state across components

## Challenging Parts

- Integrating the calendar with dynamic job deadlines and interview dates
- Managing reactive state with RxJS for live updates
- Saving data between sessions using LocalStorage
- Making the UI responsive on different screen sizes
- Filtering and sorting job applications by status or date

## Extra Features (Bonus)

- Search job applications by company or position
- Color-coded calendar events based on status
- Highlight upcoming deadlines and interviews
- Modular design for easier future updates
