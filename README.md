# 📋 Job Application Tracker

> A modern, full-featured Angular application for managing job applications with an intuitive dashboard, calendar integration, and beautiful UI design.

## ✨ Features

### 📊 Dashboard

- **Real-time Statistics** - View total applications, status breakdown, and success rates
- **Gradient Cards** - Color-coded status cards with smooth animations
- **Upcoming Interviews** - Quick overview of scheduled interviews
- **Quick Actions** - Fast access to add new applications or view calendar

### 📝 Application Management

- **Full CRUD Operations** - Create, Read, Update, and Delete job applications
- **Company Badges** - Visual company indicators with gradient backgrounds
- **Status Tracking** - Track applications through: Applied → Interviewing → Accepted/Rejected
- **Date Management** - Track application dates, interview dates, and deadlines
- **Notes System** - Add custom notes to each application

### 📅 Calendar View

- **Interactive Calendar** - Built with FullCalendar for smooth interactions
- **Event Details Panel** - Click any event to see full details
- **Color-Coded Events** - Interviews in blue, deadlines in red, other events in green
- **Monthly Overview** - See all your interviews and deadlines at a glance

### 🎨 Modern UI/UX

- **Gradient Design** - Professional gradient color scheme throughout
- **Smooth Animations** - Hover effects, transitions, and interactive elements
- **Responsive Layout** - Works perfectly on desktop, tablet, and mobile
- **Material Design** - Clean, modern interface using Angular Material
- **Custom Styling** - Over 2,500 lines of custom CSS for polished appearance

### 💾 Data Persistence

- **LocalStorage** - Automatic data saving to browser storage
- **Reactive Updates** - Real-time UI updates using RxJS BehaviorSubject
- **No Backend Required** - Runs entirely in the browser

## 🚀 Quick Start

### Prerequisites

- Node.js (v18 or higher)
- npm (v9 or higher)
- Angular CLI (v20 or higher)

### Installation

```bash
# Clone the repository
git clone https://github.com/rahma040/job-application-tracker.git

# Navigate to project directory
cd job-application-tracker

# Install dependencies
npm install

# Start development server
ng serve
```

Open your browser and navigate to **`http://localhost:4200`**
